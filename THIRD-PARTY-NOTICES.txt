Third-party software in strafe-review.exe
=========================================

Strafe Review's own code is CC0 1.0 (see LICENSE). The Windows exe also contains:

- Python (the CPython runtime and standard library), and the libraries the Windows build of Python
  ships with it (for example OpenSSL, libffi, bzip2, xz and zlib). Licence: the Python Software
  Foundation License, with the notices of those libraries; the full text is in
  PYTHON-LICENSE.txt next to this file.

- The PyInstaller bootloader, which unpacks and starts the program. Licence: GNU GPL 2.0 or later
  with the PyInstaller bootloader exception, which allows shipping programs built with it under
  any licence. https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt
